# dazift-redirect

Forwards dazift.com (and every old link on it) to the same page on https://dayzift.com.

GitHub Pages serves `404.html` for any path that does not exist here, so links like `dazift.com/invoice.html?k=...` land on `dayzift.com/invoice.html?k=...`.
